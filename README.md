# Impedance calculation of series Circuit
Copyright 2026 Raphael Elser

main.py is the main program where the impedance of a R,L,C series circuit is calculated. 

[![Linter: Ruff](https://img.shields.io/badge/Linter-Ruff-brightgreen?style=flat-square)](https://github.com/charliermarsh/ruff)

The Programm can calculate the impedance of a series circuit,
for a given frequency, inductance, capacitance and resistance.
